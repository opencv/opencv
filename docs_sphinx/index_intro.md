OpenCV (Open Source Computer Vision Library) is an open-source computer vision and machine learning software library. It has more than 2,500 optimised algorithms, a comprehensive mix of both classic and state-of-the-art computer vision and machine learning methods. These can be used to detect and recognise faces, identify objects, classify human actions in video, track camera and object motion, extract 3D models, stitch images together to produce high-resolution panoramas, and much more. The library has interfaces for C++, Python, Java, and JavaScript, runs on Windows, Linux, macOS, Android, and iOS, and accelerates work on CPU (SIMD), CUDA, OpenCL, and Vulkan.

OpenCV 5 is the major version that follows OpenCV 4.x, starting with the 5.0 release. C++17 is the minimum required standard, Python 2 support has been dropped (Python 3.6+ is required), and the legacy C API has been fully removed. New data types (CV_16BF, CV_32U, CV_64U, CV_64S, CV_Bool) and proper 0D/1D array support extend the core, while the former calib3d module is split into the geometry, calib, stereo, and ptcloud modules. A next-generation DNN engine loads ONNX and TFLite models, with ONNX Runtime integration and models hosted on Hugging Face. As of OpenCV 5.1.0, OpenCV DNN scores 83.67% on the [ONNX Backend Scoreboard](https://onnx.ai/backend-scoreboard/) and supports 170 of the 205 ONNX operators (see the [OpenCV DNN details](https://onnx.ai/backend-scoreboard/opencv_details_stable.html)). Performance gains include Universal Intrinsics 2.0 (SSE/AVX/NEON/SVE/RISC-V), Vulkan compute support, image-warping speed-ups of 10% to over 300%, and USAC as the default framework for robust estimation.

OpenCV 5.1 builds on this foundation:

- **DNN:** the classic engine has been removed, so all models run on the new engine, which gains initial CUDA support and faster CPU inference. LLM and VLM support improved with KV-cache pre-allocation, quantized `MatMulNBits` models and WordPiece/Unigram tokenizers.
- **Core:** NumPy-style broadcasting for element-wise operations, `cv::texpr` for fused element-wise expressions, FP8 data types and a complete N-D array API (`concat`, `split`, `slice`, `squeeze`, `unsqueeze` and more).
- **Imgproc:** text rendering based on HarfBuzz for complex scripts, `cv::alphaComposite` and the Oklab color space; IPP is now called through the HAL.
- **New functionality:** the `cv::XFeat` feature detector, the `cv::linearAssignment` solver, the `cv::viz3d` OpenGL visualizer with 3D Gaussian Splatting, and monocular visual odometry in `cv::slam`.
- **Video I/O and platforms:** camera enumeration and encoder controls in `VideoWriter`, plus new optimizations for Windows on ARM and RISC-V.

See the [change log](https://github.com/opencv/opencv/wiki/OpenCV-Change-Logs#version510) for the full list of changes in 5.1, including the migration notes.
